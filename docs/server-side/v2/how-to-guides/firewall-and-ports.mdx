`assets.100ms.live`
`effectssdk.ai`

## Ports

### Minimum requirement

| Ports   | Protocol | Description              |
| :------ | :------- | :----------------------- |
| 80, 443 | TCP      | API, WebSocket, TURN/TLS |

### Requirements for best experience

| Ports                  | Protocol | Description                  |
| :--------------------- | :------- | :--------------------------- |
| 80, 443, 3478          | TCP      | API, WebSocket, TURN/TLS     |
| 443, 3478, 41000-65535 | UDP      | TURN/UDP, ICE, Media traffic |
